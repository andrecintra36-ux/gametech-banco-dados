
# GameTech Informática

Projeto final de Modelagem de Banco de Dados — FATEC.

## 1. Cenário

A GameTech Informática é uma loja fictícia especializada na venda de componentes de computadores e acessórios gamer. O banco de dados foi planejado para organizar clientes, funcionários, produtos, categorias, pedidos, pagamentos e notas fiscais.
